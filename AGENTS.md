# AGENTS.md

Правила роботи в цьому репозиторії для будь-якого AI-агента (Codex, Cursor, Copilot, Gemini CLI та інших) — у файлі [`CLAUDE.md`](CLAUDE.md). Прочитай його повністю перед першою зміною: архітектура з трьох шарів, токени замість «сирих» значень, гілки і Pull Request, що робити з конфліктом. Claude Code читає `CLAUDE.md` сам; цей файл існує, щоб інші агенти працювали за тими самими правилами.

## Команди

- `npm install` — один раз після клонування
- `npm run dev` — застосунок на http://localhost:5173 (`#/dashboard`, `#/settings`, `#/ui-kit`)
- `npm run docs` — статичні сторінки `docs/` на http://127.0.0.1:8765 (лендінг, презентація, 3D, подкаст, харнес)
- `npm run typecheck && npm run build` — обовʼязково перед push і PR
- `npm run test:e2e` — Playwright; обовʼязково, якщо змінював `docs/3d/`

## Головне з CLAUDE.md

- Ніколи не коміть у `main`: гілка `feat/<екран>-<що>`, `ds/<компонент>-<що>` або `fix/<що>` від свіжого `main`, далі PR через `gh pr create` за шаблоном.
- У гілці `feat/*` не змінюй `src/components` і `src/tokens`.
- Новий проп або токен — з дефолтом, який зберігає поточний вигляд. Кожен варіант спільного компонента показаний на `#/ui-kit`.
- Не роби force push і не зливай PR сам.
