# tokens — дизайн-токени

Тільки значення: кольори, відступи, радіуси, типографіка. Жодних компонентів і жодної логіки.

| Файл | Що всередині |
|---|---|
| `colors.css` | палітра («сирі» кольори) і семантичні токени (`--color-action`, `--color-text`) |
| `spacing.css` | шкала відступів і радіуси |
| `typography.css` | шрифти й текстові стилі |
| `index.css` | збирає все разом; підключається один раз у корені застосунку |

## Правила

1. Компоненти й екрани не пишуть «сирі» значення (`#2563eb`, `14px`) — тільки `var(--…)`.
2. Зміна токена змінює весь продукт. Тому: окрема гілка `ds/tokens-<що>`, маленький PR, ревʼю обох, перевірка екрана `/ui-kit`.
3. Новий токен додаємо вільно. Існуючий перейменовуємо або видаляємо лише PR-ом, у якому оновлено всі його використання.
