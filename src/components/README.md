# components — спільні компоненти

У Figma це main components у бібліотеці. Пропси — як component properties: `<Button variant="secondary" size="sm">` — це instance з обраними властивостями.

Компонент потрапляє сюди, коли його використовують два і більше екранів («правило двох»). До того він живе в `src/screens/<екран>/components/`.

## Правила

1. Використовує тільки токени з `src/tokens`. Не імпортує нічого зі `src/screens`.
2. Публічний API — пропси. Кожен новий проп має дефолт, який зберігає поточний вигляд.
3. **Додавай варіант, не змінюй дефолт.** Потрібна менша кнопка — `size="sm"`, а не менший `padding` у `.button`. У Figma це «додати variant», а не «поправити main component».
4. Кожен компонент і кожен його варіант показаний на екрані `/ui-kit`. Це і є перевірка «нічого не зламалось».
5. Зміни тут — окрема гілка `ds/<компонент>-<що>`, маленький PR, ревʼю обох (CODEOWNERS підставляє автоматично).
6. Зміна дефолту, перейменування або видалення пропу — breaking change: спершу повідомити в чаті, у тому ж PR оновити всі використання (пошук `<Button` по проєкту).

## Структура

```
components/
├── Button/
│   ├── Button.tsx          # пропси і розмітка
│   ├── Button.module.css   # стилі тільки через var(--…)
│   └── index.ts            # export { Button }
├── Card/  Badge/  Toggle/  CodeHint/  Logo/
└── index.ts                # реекспорт → import { Button, Card } from '@/components'
```
