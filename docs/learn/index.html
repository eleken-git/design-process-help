    Презентація

    13 слайдів · ~10 хв

    Як влаштований репозиторій, навіщо гілки й Pull Request, як змінювати спільні компоненти і що робити, коли двоє змінили той самий рядок.

    Після: ви знаєте правила гри і слова, якими користуються розробники.

  2. 2

    Git у 3D

    5 епізодів · до 2 хв кожен

    Анімовані епізоди з музикою: що Git робить, коли Claude зберігає, пушить і зливає вашу роботу.

    • Конфлікт у Git1:46Двоє змінили той самий рядок: що покаже git, як це виглядає у файлі і три способи розв’язати.
    • Три стани файлу1:32Куди дівається робота, коли ви кажете Claude «збережи» і «запуш».
    • Життєвий цикл Pull Request1:41Очима рев’юерки: diff, скриншоти, коментар на рядку, схвалення і злиття.
    • Чому main захищений1:44Спроба запушити напряму, червона стіна і чотири правила, від яких вона рятує.
    • merge main vs rebase main1:44Два способи взяти свіжий main у свою гілку і чому rebase не роблять у спільній гілці.

    вдвох · 1–2 години

    1. 0Підготовка10 хв
